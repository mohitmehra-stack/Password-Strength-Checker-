# Password-Strength-Checker-
Password Strength Checker is a lightweight, responsive web application designed to help users evaluate the security level of their passwords in real-time. Built using JavaScript, CSS Glassmorphism, and HTML. it offers an intuitive visual indicator along with custom strength checks (length, numbers, uppercase/lowercase letters, and special symbols)
# 🔐 Password Strength Checker

An interactive, responsive, and visually appealing **Password Strength Checker** built using pure HTML, CSS, and Vanilla JavaScript. 

### ✨ Features
- 🚀 **Real-Time Evaluation:** Checks password strength instantly as you type.
- 🎨 **Glassmorphism UI:** Modern, clean, and sleek design using CSS backdrop filters.
- 📊 **Dynamic Visual Feedback:** Color-coded progress bar with distinct strength levels (Very Weak to Very Strong).
- 👁️ **Show/Hide Password:** Seamless toggle functionality for password visibility.
- 🛡️ **Comprehensive Logic:** Evaluates uppercase letters, lowercase letters, numbers, special characters, and minimum length.

### 🛠️ Tech Stack
- **HTML5:** Semantic structure
- **CSS3:** Glassmorphism UI, Flexbox layout, and CSS animations
- **JavaScript (ES6):** Regular Expressions (Regex) and DOM Manipulation
